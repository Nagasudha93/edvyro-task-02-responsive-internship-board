# Responsive Internship Board

## EdVyro Full Stack Development Internship — Task 02

A responsive internship listing interface built using HTML, CSS, JavaScript, and JSON.

The project allows users to search and filter internship opportunities and view internship details through an accessible, responsive interface.

---

## Features

- Responsive internship listing cards
- Internship search
- Domain filter
- Work mode filter
- Clear filters
- Internship details dialog
- Internship application form
- Form validation
- Loading state
- Empty-result state
- Error state with retry
- Keyboard-friendly navigation
- Accessible form labels
- Responsive layout for mobile, tablet, and desktop
- Internship data loaded from JSON
- Local browser storage for demo application records

---

## Technologies Used

- HTML5
- CSS3
- JavaScript
- JSON
- Browser DOM APIs
- LocalStorage

No frontend framework is used.
